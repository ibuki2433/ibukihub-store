# 💜 Bull Software Store - ระบบเว็บ E-Commerce ขายโปรแกรมและซอฟต์แวร์

ระบบร้านค้าออนไลน์สำหรับจัดจำหน่ายโปรแกรมและซอฟต์แวร์ที่พัฒนาขึ้นเอง (เช่น `IbukiDownload_v2.5_Portable.zip`, เครื่องมือ Automation, ซอฟต์แวร์เดสก์ท็อป และเครื่องมือช่าง) ออกแบบด้วยโทนสี **ม่วงอ่อน (Soft Violet / Lavender)** สวยงาม เรียบหรู ทันสมัย ไม่ฉูดฉาด ใช้ฟอนต์ภาษาไทยแบบไม่มีหัว (IBM Plex Sans Thai & Prompt) ไร้การใช้อิโมจิรกรุงรัง ให้ความรู้สึกน่าเชื่อถือระดับสตูดิโอซอฟต์แวร์มืออาชีพ

---

## 🚀 ฟังก์ชันหลักของระบบ

1. **ระบบจัดส่งซอฟต์แวร์และคีย์อัตโนมัติ (Automated Delivery)**:
   - ออก **License Key** ประจำตัวซอฟต์แวร์ทันทีหลังชำระเงิน
   - ลิงก์ดาวน์โหลดส่งมอบไฟล์ `.zip` จริงของโปรแกรม (รวมถึง `IbukiDownload_v2.5_Portable.zip` ขนาด 205MB)
   - หน้า **"คลังโปรแกรม (My Library)"** ให้ลูกค้าสามารถเข้ามาคัดลอก License Key และดาวน์โหลดไฟล์ซ้ำได้ตลอดชีพ

2. **ระบบกระเป๋าเงินและเติมเงิน (Wallet & Top-up)**:
   - พร้อมเพย์ QR Code (PromptPay QR) คำนวณยอดเงินและสร้าง QR แบบเรียลไทม์
   - ซองของขวัญทรูมันนี่ (TrueMoney Gift Link)

3. **แผงควบคุมระบบสำหรับผู้ดูแล (Admin Center)**:
   - **เพิ่มซอฟต์แวร์ใหม่**: มีปุ่มอัปโหลดไฟล์แพ็กเกจ `.zip` จากคอมพิวเตอร์ของคุณขึ้นระบบโดยตรง
   - **จัดการ License Keys**: เติมสต็อกคีย์ทีละหลายบรรทัด
   - **รายงานภาพรวม**: ตรวจสอบรายการคำสั่งซื้อ, ประวัติการเติมเงิน, และแก้ไขประกาศหน้าร้าน

## 💻 วิธีการเปิดใช้งานเว็บ (Quick Start)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เดียวบน Windows
- ดับเบิ้ลคลิกที่ไฟล์ **`start.bat`**
- ระบบจะเปิดหน้าต่างเบราว์เซอร์ไปยัง `http://localhost:5000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน PowerShell / Terminal
```bash
# รันเซิร์ฟเวอร์
npm start
```
เปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:5000`
